### What I learned

How to use dynamic page routes with data from JSON files to generate the individual planet pages but only building and styling them once. This offers great flexibility for adding future data e.g. new planets in different solar systems.

### Continued Development

I struggled a bit with the formatting differences between mobile and tablet/desktop. Mostly my struggles came from the placement of the tab buttons. I didn't want to create two sets of buttons due to the accessibility of the tab panels I set up. However, this presented issues with the placement in CSS. I solved it using CSS Grid, but i'm sure there's a more elegant solution I am missing.
